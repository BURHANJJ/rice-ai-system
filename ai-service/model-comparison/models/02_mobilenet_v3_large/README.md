# MobileNetV3-Large

**Howard et al., ICCV 2019** · CNN สำหรับมือถือ · โมเดลเปรียบเทียบ

ออกแบบมาเพื่อมือถือโดยเฉพาะ ใช้ depthwise separable convolution, Squeeze-and-Excitation และ hard-swish โครงสร้างหาด้วย Neural Architecture Search ให้เร็วบน CPU ของมือถือ

**ทำไมถึงเลือกมาเทียบ:** เป็นคู่แข่งโดยตรงของงานที่ต้องรันบนเครื่องผู้ใช้ ใช้ตอบว่าถ้าอยากได้โมเดลที่เล็กและเร็วกว่านี้ ต้องเสียความแม่นเท่าไร

## ข้อมูลโมเดล

|---|---|

## ไฟล์ในโฟลเดอร์

แต่ละ `seed-*/` มี

| ไฟล์ | คืออะไร |
|---|---|
| `model.keras` | โมเดลที่เทรนแล้ว (ไม่อยู่ใน git เพราะไฟล์ใหญ่ สร้างใหม่ด้วย `train.py`) |
| `model.tflite` | แปลงเป็น TFLite Float16 (เฉพาะ seed 42, ไม่อยู่ใน git) |
| `metrics.json` | ผลวัดทั้งหมด รวม confusion matrix และผลรายคลาส |
| `test_probs.npy` | ความน่าจะเป็นที่ทายภาพทดสอบทั้ง 761 ภาพ ใช้คำนวณสถิติซ้ำได้ |
| `history.json`, `log_*.csv` | ความแม่นยำและ loss ทุกรอบการเทรน |
| `train_info.json` | เวลาที่ใช้ อุปกรณ์ เวอร์ชันไลบรารี และสูตรที่ใช้จริง |
