# DenseNet-121

**Huang et al., CVPR 2017** · CNN (dense connections) · โมเดลเปรียบเทียบ

ทุกชั้นในบล็อกรับข้อมูลจากทุกชั้นก่อนหน้า (dense connection) ทำให้ใช้ลักษณะเด่นซ้ำได้มากและพารามิเตอร์ไม่สูง

**ทำไมถึงเลือกมาเทียบ:** นิยมใช้ในงานจำแนกโรคพืชและภาพทางการแพทย์ เป็นตัวแทนของ CNN ขนาดกลาง

## ข้อมูลโมเดล

| | |
|---|---|
| พารามิเตอร์ | 7.04 ล้าน |
| FLOPs ต่อภาพ | 5.70 GFLOPs |
| ไฟล์ Keras | 29.7 MB |
| ไฟล์ TFLite Float16 (แบบที่แอปมือถือใช้) | 14.1 MB · ทายตรงกับ Keras 100.00% ของภาพ |
| เวลาต่อภาพ TFLite บน CPU (4 threads, ค่ามัธยฐาน) | 18.4 ms |
| เวลาต่อภาพ Keras บน CPU | 56.1 ms |
| การปรับค่าพิกเซล | หาร 255 แล้วปรับด้วยค่าเฉลี่ยและ SD ของ ImageNet (ชั้น ImageNetPreprocess) |
| learning rate ช่วง fine-tune | 0.0001 |

## ผลบนชุดทดสอบ 761 ภาพ

เฉลี่ย 3 seed: **Accuracy 96.58 ± 0.46%** · Macro F1 95.68 ± 0.48% · AUC 0.9968

| seed | Accuracy | Macro F1 | AUC | epoch จริง (ช่วง 1 + 2) | เวลาเทรน (GPU) |
|---|---|---|---|---|---|

| 7 | 96.32% (733/761) | 95.47% | 0.9953 | 4 + 18 | 23.9 นาที |
| 2026 | 96.32% (733/761) | 95.33% | 0.9977 | 6 + 18 | 25.6 นาที |

## ไฟล์ในโฟลเดอร์

แต่ละ `seed-*/` มี

| ไฟล์ | คืออะไร |
|---|---|
| `model.keras` | โมเดลที่เทรนแล้ว (ไม่อยู่ใน git เพราะไฟล์ใหญ่ สร้างใหม่ด้วย `train.py`) |
| `model.tflite` | แปลงเป็น TFLite Float16 (เฉพาะ seed 42, ไม่อยู่ใน git) |

| `test_probs.npy` | ความน่าจะเป็นที่ทายภาพทดสอบทั้ง 761 ภาพ ใช้คำนวณสถิติซ้ำได้ |

| `train_info.json` | เวลาที่ใช้ อุปกรณ์ เวอร์ชันไลบรารี และสูตรที่ใช้จริง |
