# VGG-16

**Simonyan & Zisserman, ICLR 2015** · CNN แบบดั้งเดิม · โมเดลเปรียบเทียบ

CNN รุ่นแรก ๆ ที่ซ้อน convolution 3x3 ลึก 16 ชั้น ไม่มี BatchNorm และไม่มี residual

**ทำไมถึงเลือกมาเทียบ:** เป็น baseline แบบดั้งเดิมที่งานวิจัยส่วนใหญ่ใช้อ้างอิง แสดงว่าสถาปัตยกรรมใหม่ดีกว่าแบบเก่าแค่ไหน

> **ข้อยกเว้นของสูตร:** ช่วง fine-tune ใช้ learning rate 0.00001 แทน 0.0001 เพราะที่ 0.0001 โมเดลพัง (val accuracy ตกจาก 60% เหลือ 35% และ loss ค้างที่ 1.386 = ทายทุกคลาสเท่ากัน) บันทึกการทดลองนั้นอยู่ใน `lr-1e-4-diverged/`
