# ResNet-50

**He et al., CVPR 2016** · CNN (residual) · โมเดลเปรียบเทียบ

ใช้ residual connection (ทางลัดข้ามชั้น) ทำให้เทรนเครือข่ายลึก 50 ชั้นได้โดยไม่เสื่อม

**ทำไมถึงเลือกมาเทียบ:** เป็น baseline มาตรฐานที่สุดของงานจำแนกภาพ เกือบทุกงานวิจัยใช้เทียบ

## ข้อมูลโมเดล

| | |
|---|---|
| พารามิเตอร์ | 23.60 ล้าน |
| FLOPs ต่อภาพ | 7.75 GFLOPs |
| ไฟล์ Keras | 95.1 MB |
| ไฟล์ TFLite Float16 (แบบที่แอปมือถือใช้) | 47.1 MB · ทายตรงกับ Keras 100.00% ของภาพ |
| เวลาต่อภาพ TFLite บน CPU (4 threads, ค่ามัธยฐาน) | 21.3 ms |
| เวลาต่อภาพ Keras บน CPU | 40.0 ms |
| การปรับค่าพิกเซล | สลับ RGB เป็น BGR แล้วลบค่าเฉลี่ย ImageNet (ชั้น ImageNetPreprocess) |
| learning rate ช่วง fine-tune | 0.0001 |

## ผลบนชุดทดสอบ 761 ภาพ

## ไฟล์ในโฟลเดอร์

แต่ละ `seed-*/` มี

| ไฟล์ | คืออะไร |
|---|---|
| `model.keras` | โมเดลที่เทรนแล้ว (ไม่อยู่ใน git เพราะไฟล์ใหญ่ สร้างใหม่ด้วย `train.py`) |
| `model.tflite` | แปลงเป็น TFLite Float16 (เฉพาะ seed 42, ไม่อยู่ใน git) |
| `metrics.json` | ผลวัดทั้งหมด รวม confusion matrix และผลรายคลาส |
| `test_probs.npy` | ความน่าจะเป็นที่ทายภาพทดสอบทั้ง 761 ภาพ ใช้คำนวณสถิติซ้ำได้ |
| `history.json`, `log_*.csv` | ความแม่นยำและ loss ทุกรอบการเทรน |
| `train_info.json` | เวลาที่ใช้ อุปกรณ์ เวอร์ชันไลบรารี และสูตรที่ใช้จริง |
