# ConvNeXt-Tiny

**Liu et al., CVPR 2022** · CNN สมัยใหม่ (แนวคิดจาก Transformer) · โมเดลเปรียบเทียบ

CNN ที่ออกแบบใหม่โดยยืมแนวคิดจาก Vision Transformer เช่น kernel 7x7, LayerNorm และ GELU ให้ผลใกล้เคียง Transformer แต่ยังเป็น convolution

**ทำไมถึงเลือกมาเทียบ:** เป็นตัวแทนของโมเดลสมัยใหม่ (2022) ใช้ตอบว่าโมเดลใหม่และใหญ่กว่าช่วยให้แม่นขึ้นจริงหรือไม่

## ข้อมูลโมเดล

| | |
|---|---|
| พารามิเตอร์ | 27.82 ล้าน |
| FLOPs ต่อภาพ | 8.76 GFLOPs |
| ไฟล์ Keras | 111.8 MB |
| ไฟล์ TFLite Float16 (แบบที่แอปมือถือใช้) | 55.9 MB · ทายตรงกับ Keras 100.00% ของภาพ |
| เวลาต่อภาพ TFLite บน CPU (4 threads, ค่ามัธยฐาน) | 44.3 ms |
| เวลาต่อภาพ Keras บน CPU | 98.6 ms |
| การปรับค่าพิกเซล | อยู่ในตัวโมเดลแล้ว (รับค่า 0-255) |
| learning rate ช่วง fine-tune | 0.0001 |

## ไฟล์ในโฟลเดอร์

แต่ละ `seed-*/` มี

| ไฟล์ | คืออะไร |
|---|---|
| `model.keras` | โมเดลที่เทรนแล้ว (ไม่อยู่ใน git เพราะไฟล์ใหญ่ สร้างใหม่ด้วย `train.py`) |
| `model.tflite` | แปลงเป็น TFLite Float16 (เฉพาะ seed 42, ไม่อยู่ใน git) |
| `metrics.json` | ผลวัดทั้งหมด รวม confusion matrix และผลรายคลาส |
| `test_probs.npy` | ความน่าจะเป็นที่ทายภาพทดสอบทั้ง 761 ภาพ ใช้คำนวณสถิติซ้ำได้ |
| `history.json`, `log_*.csv` | ความแม่นยำและ loss ทุกรอบการเทรน |
| `train_info.json` | เวลาที่ใช้ อุปกรณ์ เวอร์ชันไลบรารี และสูตรที่ใช้จริง |
