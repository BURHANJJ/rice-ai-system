# EfficientNet-B0

**Tan & Le, ICML 2019** · CNN (compound scaling) · โมเดลหลักของระบบ

โมเดลหลักของ Rice AI ขยายความกว้าง ความลึก และขนาดภาพของเครือข่ายพร้อมกันอย่างสมดุล (compound scaling) ใช้บล็อก MBConv กับ Squeeze-and-Excitation จึงได้ความแม่นสูงโดยใช้พารามิเตอร์น้อย

**ทำไมถึงเลือกมาเทียบ:** เป็นสถาปัตยกรรมเดียวกับโมเดลที่ระบบใช้งานจริง (V2) เทรนซ้ำที่นี่ด้วยสภาพแวดล้อมเดียวกับโมเดลอื่น เพื่อให้เทียบกันได้ตรง ๆ

## ไฟล์ในโฟลเดอร์

แต่ละ `seed-*/` มี

| ไฟล์ | คืออะไร |
|---|---|
| `model.keras` | โมเดลที่เทรนแล้ว (ไม่อยู่ใน git เพราะไฟล์ใหญ่ สร้างใหม่ด้วย `train.py`) |
| `model.tflite` | แปลงเป็น TFLite Float16 (เฉพาะ seed 42, ไม่อยู่ใน git) |

| `test_probs.npy` | ความน่าจะเป็นที่ทายภาพทดสอบทั้ง 761 ภาพ ใช้คำนวณสถิติซ้ำได้ |
| `history.json`, `log_*.csv` | ความแม่นยำและ loss ทุกรอบการเทรน |
| `train_info.json` | เวลาที่ใช้ อุปกรณ์ เวอร์ชันไลบรารี และสูตรที่ใช้จริง |
