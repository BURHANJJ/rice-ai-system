# การเทรนโมเดล (รุ่นที่ 2)

โฟลเดอร์นี้เก็บสคริปต์ที่ใช้เทรนโมเดลตัวที่ระบบใช้อยู่ตอนนี้ (`ai-service/model/rice_disease_model.keras` เทรนเมื่อ 11 ต.ค. 2569)

รูปภาพและผลการเทรนไม่ได้อยู่ในโปรเจกต์ เพราะไฟล์ใหญ่ เก็บไว้ที่ `D:/rice-eval` ถ้าย้ายไปไว้ที่อื่นให้ตั้งตัวแปร `RICE_EVAL_DIR` ให้ชี้ไปที่โฟลเดอร์ใหม่

## ทำไมต้องเทรนใหม่

โมเดลรุ่นแรกที่เทรนใน Colab ได้ความแม่นยำแค่ประมาณ 70% เพราะตอนเทรนล็อกชั้นของ EfficientNetB0 ไว้เกือบทั้งหมด และใช้ learning rate ต่ำมากตอน fine-tune โมเดลเลยเรียนรู้ลักษณะของใบข้าวได้ไม่พอ

รุ่นที่ 2 แก้ด้วยการปลดล็อกให้ทั้งโมเดลได้เรียนรู้ และแยกภาพชุดทดสอบออกมาต่างหากตั้งแต่แรก เพื่อให้ตัวเลขความแม่นยำที่วัดได้เชื่อถือได้จริง

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `train.py` | แบ่งภาพเป็น 3 ชุด (เทรน 70% / ตรวจสอบ 15% / ทดสอบ 15%) แล้วเทรน 2 ช่วง ช่วงแรกเทรนแค่ชั้นสุดท้าย 6 รอบ ช่วงที่สองปลดล็อกทั้งโมเดลเทรนต่ออีก 18 รอบ |
| `test_eval.py` | เอาภาพชุดทดสอบมาวัดผลโมเดลทั้งรุ่นเก่าและรุ่นใหม่ แปลงโมเดลเป็น TFLite สำหรับมือถือ และวาดกราฟที่ใช้ในรายงาน |
| `bench.py` | ส่งภาพ 200 ภาพไปที่ AI service ที่เปิดอยู่ แล้วจับเวลาว่าแต่ละภาพใช้เวลาตอบกี่มิลลิวินาที |
| `evaluate.py` | วัดผลโมเดลรุ่นแรกซ้ำแบบเดียวกับใน Colab เพื่อยืนยันว่าได้ 70.26% จริง |
| `colab_v1_th.ipynb` | โน้ตบุ๊ก Colab ที่ใช้เทรนรุ่นแรก |
| `colab_v1_with_outputs.ipynb` | โน้ตบุ๊กเดียวกันแต่มีผลลัพธ์ตอนรันเก็บไว้ด้วย |

## วิธีรัน

ติดตั้งไลบรารีก่อน

```bash
pip install tensorflow scikit-learn matplotlib kaggle
```

**1. เตรียมภาพ**

ดาวน์โหลดชุดข้อมูล Paddy Doctor จาก Kaggle (ต้องมีไฟล์ `kaggle.json` และกดยอมรับกติกาการแข่งขันในเว็บ Kaggle ก่อน)

```bash
kaggle competitions download -c paddy-disease-classification -p D:/rice-eval
```

แตกไฟล์เฉพาะ 4 โฟลเดอร์ที่ใช้ คือ `blast`, `bacterial_leaf_blight`, `tungro`, `normal` ไปไว้ที่ `D:/rice-eval/raw/train_images` จากนั้นรัน `evaluate.py` หนึ่งครั้ง สคริปต์จะย้ายภาพไปไว้ที่ `D:/rice-eval/rice4/` และเปลี่ยนชื่อโฟลเดอร์เป็น `BLAST`, `BLB`, `TUNGRO`, `HEALTHY` ให้เอง

```bash
python evaluate.py
```

**2. เทรน**

```bash
python train.py
```

บนเครื่องที่ใช้พัฒนา (CPU i5-12450H) ใช้เวลาประมาณ 45 นาที ถ้ารันใน Colab ที่มี GPU จะเร็วกว่านี้มาก

**3. วัดผลและแปลงเป็น TFLite**

```bash
python test_eval.py
```

ผลจะอยู่ใน `D:/rice-eval/run/test_metrics.json` ส่วนกราฟอยู่ใน `D:/rice-eval/report/fig/`

**4. วัดความเร็วของเซิร์ฟเวอร์ (ถ้าต้องการ)**

เปิด AI service ก่อน (`python main.py` ในโฟลเดอร์ `ai-service`) แล้วรัน

```bash
python bench.py
```

## เอาโมเดลใหม่ไปใช้

1. ก๊อปไฟล์ `run/rice_disease_model.keras` กับ `run/class_indices.json` ไปทับใน `ai-service/model/` (ก๊อปไฟล์เดิมสำรองไว้ก่อน)
2. แก้ `ai-service/model/metrics.json` ให้เป็นผลจาก `run/test_metrics.json` ตัวเลขความแม่นยำที่แสดงในแอปและหน้าเว็บอ่านมาจากไฟล์นี้
3. ก๊อป `run/rice_disease_model.tflite` กับ `class_indices.json` ไปที่ `mobile/assets/model/` สำหรับการวิเคราะห์แบบออฟไลน์บนมือถือ
4. ปิดแล้วเปิด AI service ใหม่ และ build แอปมือถือใหม่

## ผลที่ได้

วัดกับภาพชุดทดสอบ 761 ภาพที่โมเดลไม่เคยเห็นตอนเทรน

| | รุ่นแรก (Colab) | รุ่นที่ 2 |
|---|---|---|
| ความแม่นยำ | 75.43% | **97.90%** |
| F1 เฉลี่ย | 0.714 | **0.978** |

ความแม่นยำของรุ่นแรกในตารางนี้สูงกว่าที่วัดใน Colab (70.26%) เพราะภาพทดสอบบางส่วนเคยอยู่ในชุดที่ใช้เทรนรุ่นแรก ตัวเลขนี้จึงเข้าข้างรุ่นแรกอยู่แล้ว

ไฟล์ TFLite มีขนาด 8.2 MB และทายผลตรงกับโมเดลเต็มทุกภาพ

ภาพทั้งหมดมาจากแปลงนาในอินเดีย (ชุดข้อมูล Paddy Doctor) ความแม่นยำเมื่อใช้กับภาพจากแปลงนาในไทยอาจต่ำกว่านี้ ระบบจึงมีหน้า "ตรวจทานผล AI" ไว้เก็บภาพที่ผู้ดูแลยืนยันผลแล้ว เพื่อเอามาเทรนเพิ่มในรอบต่อไป
