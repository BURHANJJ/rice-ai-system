# การเทรนโมเดล

## รุ่นที่ 3 (ใช้งานอยู่ตอนนี้, 17 ต.ค. 2569)

รุ่นที่ 2 รู้จักแค่ 4 คำตอบ เวลาเกษตรกรถ่ายใบที่เป็นโรคอื่น เช่น ใบจุดสีน้ำตาล โมเดลต้องตอบเป็นหนึ่งใน 4 โรคเสมอ และ 37% ของภาพเหล่านี้ผ่านเกณฑ์ความมั่นใจออกไปเป็นผลวินิจฉัยที่ผิด รุ่นที่ 3 เพิ่มคลาสที่ 5 `OTHER` ฝึกจากโรคอีก 6 ชนิดใน Paddy Doctor (5,338 ภาพ) เมื่อโมเดลทาย `OTHER` ระบบตอบว่า "อาจเป็นโรคที่ระบบยังไม่รองรับ ให้ปรึกษาเจ้าหน้าที่" (error `out_of_scope`)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `prepare_v3_data.py` | รวม 4 คลาสเดิม (แบ่งชุดเดิม ชุดทดสอบ 761 ภาพเดิม) กับภาพโรคอื่น แบ่ง 70/15/15 ตามชนิดโรค |
| `train_v3.py` | เทรน EfficientNet-B0 5 คลาส 3 seed บน GPU สูตรเดียวกับรุ่นที่ 2 |
| `build_v3.py` | เลือก seed ด้วย validation accuracy, เลือกเกณฑ์ความมั่นใจด้วย validation, วัดผลเทียบรุ่นที่ 2, แปลง TFLite แล้วติดตั้ง |

**การตัดสินใจทั้งหมดใช้ชุด validation** ชุดทดสอบใช้วัดผลครั้งสุดท้ายเท่านั้น
- เลือก seed 2026 (validation accuracy 96.35% สูงสุดใน 3 seed)
- เกณฑ์ความมั่นใจ 60% เลือกโดยให้คะแนน +1 ต่อคำตอบที่ถูก และ −2 ต่อผลวินิจฉัยผิด ค่านี้อยู่ใน `model/metrics.json` (`threshold`) และ `mobile/assets/model/model_config.json` service กับแอปอ่านค่าเดียวกัน
- ลอง temperature scaling แล้วไม่ใช้: ทำให้ % ความมั่นใจตรงความจริงขึ้น (ECE 9% → 1%) แต่โมเดลมั่นใจกับภาพโรคอื่นมากขึ้นด้วย ภาพโรคอื่นผ่านเกณฑ์เพิ่มจาก 49% เป็น 79% (ทดลองกับรุ่น 4 คลาส)

**ผลบนชุดทดสอบ** (ตามที่ผู้ใช้เจอจริง: V2 ใช้เกณฑ์ 75%, V3 ใช้ 60%)

| | รุ่นที่ 2 | รุ่นที่ 3 |
|---|---|---|
| ภาพโรคอื่น 801 ภาพ ที่ได้ชื่อโรคผิด | 299 | **16** |
| ภาพ 4 คลาส 761 ภาพ ที่ระบบตอบผล | 92.8% | **95.7%** |
| ภาพ 4 คลาส ที่ตอบผิดโรค | 2 | 3 |
| Accuracy 4 คลาส | 97.90% | 96.85% |

Accuracy 4 คลาสลดลงเพราะภาพโรคที่รองรับ 15 ภาพถูกจัดเป็น `OTHER` (ผู้ใช้ได้คำแนะนำให้ปรึกษาเจ้าหน้าที่ ไม่ใช่ชื่อโรคผิด) McNemar ระหว่างสองรุ่นบน 761 ภาพ p = 0.096 ไม่มีนัยสำคัญ ไฟล์ TFLite 8.1 MB ทายตรงกับ Keras ทุกภาพ ผลทั้งหมดอยู่ใน `model/metrics.json`

รุ่นที่ 2 ไม่ได้รวมอยู่ใน repo นี้ เก็บไว้เฉพาะผลวัด (`model/metrics.v2.json`, `model/version_comparison.json`) ถ้าต้องการย้อนกลับให้เทรนซ้ำด้วย `train.py` แล้วใช้ `class_indices.json` 4 คลาส และลบ `mobile/assets/model/model_config.json`

```bash
python prepare_v3_data.py                                         # Python ที่มี TensorFlow
set KERAS_BACKEND=torch && D:/rice-eval/venv-gpu/Scripts/python train_v3.py   # GPU ราว 2 ชั่วโมง
python build_v3.py                                                # เลือก วัดผล ติดตั้ง
```

## ทำไมต้องเทรนใหม่

โมเดลรุ่นแรกที่เทรนใน Colab ได้ความแม่นยำแค่ประมาณ 70% เพราะตอนเทรนล็อกชั้นของ EfficientNetB0 ไว้เกือบทั้งหมด และใช้ learning rate ต่ำมากตอน fine-tune โมเดลเลยเรียนรู้ลักษณะของใบข้าวได้ไม่พอ

รุ่นที่ 2 แก้ด้วยการปลดล็อกให้ทั้งโมเดลได้เรียนรู้ และแยกภาพชุดทดสอบออกมาต่างหากตั้งแต่แรก เพื่อให้ตัวเลขความแม่นยำที่วัดได้เชื่อถือได้จริง

> การเปรียบเทียบกับโมเดลอื่น 5 สถาปัตยกรรม (MobileNetV3, DenseNet121, VGG16, ResNet50, ConvNeXt-Tiny) อยู่ที่ [`../model-comparison/`](../model-comparison/README.md)

## เอาโมเดลใหม่ไปใช้

ระบบไม่มีเซิร์ฟเวอร์ AI โมเดลทำงานบนอุปกรณ์ จึงต้องส่งไฟล์ไป 2 ที่

1. ก๊อปไฟล์ `run/rice_disease_model.keras` กับ `run/class_indices.json` ไปทับใน `ai-service/model/` (สำรองไฟล์เดิมไว้ก่อน) และแก้ `metrics.json` ให้เป็นผลจาก `run/test_metrics.json`
2. **แอป**: ก๊อป `run/rice_disease_model.tflite`, `class_indices.json` และ `model_config.json` (เกณฑ์ความมั่นใจ) ไปที่ `mobile/assets/model/` แล้ว build แอปรุ่นใหม่
3. **เว็บ**: รัน `KERAS_BACKEND=torch python export_onnx.py` ได้ไฟล์ `web/public/models/rice-v3.onnx` สคริปต์จะเทียบคำตอบกับโมเดลต้นฉบับบนภาพทดสอบให้ด้วย จากนั้นแก้ตัวเลขใน `web/src/lib/systemStatus.js` และ `web/src/lib/trialScan.js` (ถ้าเกณฑ์เปลี่ยน) แล้ว deploy เว็บ

## ผลที่ได้

วัดกับภาพชุดทดสอบ 761 ภาพที่โมเดลไม่เคยเห็นตอนเทรน

| | รุ่นแรก (Colab) | รุ่นที่ 2 |
|---|---|---|
| ความแม่นยำ | 75.43% | 97.90% |
| F1 เฉลี่ย | 0.714 | 0.978 |

ความแม่นยำของรุ่นแรกในตารางนี้สูงกว่าที่วัดใน Colab (70.26%) เพราะภาพทดสอบบางส่วนเคยอยู่ในชุดที่ใช้เทรนรุ่นแรก ตัวเลขนี้จึงเข้าข้างรุ่นแรกอยู่แล้ว

ไฟล์ TFLite มีขนาด 8.2 MB และทายผลตรงกับโมเดลเต็มทุกภาพ

ภาพทั้งหมดมาจากแปลงนาในอินเดีย (ชุดข้อมูล Paddy Doctor) ความแม่นยำเมื่อใช้กับภาพจากแปลงนาในไทยอาจต่ำกว่านี้ ระบบจึงมีหน้า "ตรวจทานผล AI" ไว้เก็บภาพที่ผู้ดูแลยืนยันผลแล้ว เพื่อเอามาเทรนเพิ่มในรอบต่อไป
